# Security policy

## Supported versions

Only the latest published version of `opencode-applefm-compat` is supported.

## Reporting a vulnerability

Please report security issues privately using GitHub's **Security → Report a vulnerability** on this repository.

Do not open a public issue for security reports.

Include:

- affected version
- steps to reproduce
- potential impact
- suggested fix, if any

You should receive an acknowledgement within a few days.
